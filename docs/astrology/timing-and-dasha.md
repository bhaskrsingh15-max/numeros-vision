# Numeros Vision — Dasha & Timing Window Normalisation
**Document Type:** Timing Engine Specification

## 1. Normalisation Rules
1. Every timing event is represented with an explicit start date and end date (`YYYY-MM-DD`).
2. Numerology Personal Year (annual calendar cycle) and Mahadasha (multi-year planetary ruler cycle) are calculated separately from Astrological Dasha (Vimshottari Dasha/Antardasha).
3. **Consensus Rule:** Two timing claims can only be compared for consensus if their calendar intervals overlap.
4. If intervals do not overlap, they are classified as `not_comparable` rather than conflicting.
