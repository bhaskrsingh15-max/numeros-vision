## 1. Six-Layer Controlled Architecture
1. **Calculation Layer:** Authoritative, 100% deterministic pure Python engines executing independently from validated inputs.
2. **Characteristics Layer:** Sourced, tradition-specific interpretation atlases mapping numbers, compound sums, repeated/missing values, planetary states, and time periods to a shared 20-theme taxonomy.
3. **Evidence Layer:** RAG retrieval over 10,826 verified classical passages with metadata provenance, content hashing, and source privacy masking.
4. **Consensus Layer:** Correlation-aware cross-system synthesis that groups correlated system families, detects time-window overlap, and calculates convergence ratios without false probability claims.
5. **Guidance Layer:** Sourced Vedic lifestyle adjustments (Dinacharya circadian routines, Sattvic habits, mindful pauses), safe crystal/gemstone recommendations (with planetary enemy exclusions and statutory disclaimers), and sacred Yantras.
6. **Evaluation Layer:** Consented, quarantined feedback ledger tracking Subjective Resonance, Factual Fit, Specificity, Usefulness, and Future Outcomes separately, preventing uncontrolled live model drift.
