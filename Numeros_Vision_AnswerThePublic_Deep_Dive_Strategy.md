## 3. Search Intent Classification

### 3.1 Informational intent

The user wants to understand a concept, learn a method, or explore an interpretation.

Examples:

- What is numerology?
- How is numerology calculated?
- Numerology number meanings
- Chaldean numerology explained
- What does Life Path Number 8 mean?
- What is a Lo Shu grid?
- How do missing numbers work in a Lo Shu grid?
- What is the difference between a birth number and a Life Path Number?
- How accurate is numerology?

**Recommended content types:**

- Comprehensive guides
- Tutorials
- Reference charts
- Number-meaning articles
- Educational FAQs
- Worked examples

### 3.2 Commercial investigation intent

The user is comparing methods, tools, reports, or services before deciding what to use.

Examples:

- Chaldean vs. Pythagorean numerology
- Name numerology vs. date-of-birth numerology
- Free vs. paid numerology report
- Numerology calculator vs. numerologist consultation
- Which numerology calculator should I use?
- What does a detailed numerology report include?

**Recommended content types:**

- Comparison guides
- Product explainers
- Sample reports
- Feature comparison pages
- Methodology pages
- Pricing and service pages, if offered

### 3.3 Transactional and tool-use intent

The user wants to calculate a number, generate a result, use a tool, purchase a report, or complete another action.

Examples:

- Numerology calculator by name
- Numerology calculator by date of birth
- Life Path calculator
- Business name numerology calculator
- Mobile number numerology calculator
- Numerology compatibility calculator
- Personal year numerology calculator
- Buy a detailed numerology report

**Recommended destinations:**

- Working calculator pages
- Calculator hub
- Report purchase pages, if available
- Consultation booking pages, if offered
- Account or dashboard pages, if implemented

Do not publish a calculator landing page as if a tool exists when the feature has not been implemented or validated.

### 3.4 Navigational intent

The user wants to find a specific brand or page.

Examples:

- Numeros Vision login
- Numeros Vision calculator
- Numeros Vision report
- Numeros Vision methodology

**Recommended destinations:**

- Homepage
- Login page, if implemented
- Calculator hub
- Report pages
- Methodology page

### 3.5 Mixed intent

Some searches may contain both informational and transactional intent. Inspect the current search results and choose one dominant purpose for each URL.

Do not create multiple pages targeting the same query when the same page can satisfy the search need comprehensively.

## 4. AnswerThePublic Research Workflow

Research tool: https://answerthepublic.com/

### Step 1: Website-based discovery

Enter:

`https://numerosvision.com`

Choose English and India where those options are available.

Review:

- Suggested keyword opportunities
- Existing keyword coverage
- Related search questions
- Search modifiers
- Topic gaps
- Competitor or keyword coverage features, where available

**Output:** An initial list of topics that may be missing from the website.

### Step 2: Run broad seed keywords separately

Run separate searches for:

1. Numerology
2. Numerology calculator
3. Name numerology
4. Numerology number meanings
5. Life Path Number
6. Chaldean numerology
7. Pythagorean numerology
8. Lo Shu grid
9. Business name numerology
10. Mobile number numerology
11. Numerology compatibility
12. Personal year numerology
13. Numerology report
14. Numerology alphabet chart

Do not rely only on one broad search. Each seed can reveal a different group of questions and modifiers.

### Step 3: Export question-based keywords

Review question patterns such as:

- What is...?
- How do you...?
- Why does...?
- Can...?
- Does...?
- Is...?
- When...?
- Which...?
- What does ... mean?
- How accurate is...?

Use the resulting questions to improve article outlines, FAQs, tutorials, and calculator explanations.

Do not automatically create a separate article for every question.

### Step 4: Explore comparison keywords

Look for queries containing:

- vs.
- versus
- comparison
- best
- better
- difference between
- which should I use
- free vs. paid

Create comparison pages only when the search results indicate that users want a comparison.

### Step 5: Keep platforms separate

Maintain separate source labels for:

- Google
- Bing
- YouTube
- Instagram
- Amazon
- Other supported platforms

Use YouTube and social searches for video and social content ideas. Do not assume that a question discovered on a social platform has the same Google search demand.

### Step 6: Validate search demand

For each priority keyword, record:

- Keyword
- Source platform
- Country
- Language
- Estimated monthly search volume
- CPC, where available
- Current ranking URL, if any
- Search intent
- Search result types
- Content format required
- Existing page overlap
- Proposed URL
- Priority
- Validation date

Use Google Search Console, Google Trends, keyword research tools, and live SERPs to validate important terms.

### Step 7: Perform a content gap audit

Classify each topic as:

- Covered
- Partially covered
- Not covered
- Needs consolidation
- Needs content refresh
- Requires a new functional tool
- Not relevant to the product

Do not create new pages until existing URLs have been reviewed.

### Step 8: Assign one primary intent to each URL

Every indexable page should have:

- One primary query or tightly connected query group
- One dominant search intent
- One clear purpose
- A unique content angle
- A relevant internal-linking path
- A clear next action for the visitor
